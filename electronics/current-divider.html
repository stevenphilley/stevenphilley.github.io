Current divider

Two resistors in parallel share a source current. More current takes the easier path — the smaller resistance. Change Iin, R1, and R2 — the branch currents update as you type.

How it works

R1 and R2 sit side by side across the same voltage. The source current Iin splits between them in inverse proportion to resistance: I1 = Iin × R2 / (R1 + R2), and I2 = Iin × R1 / (R1 + R2). Equal resistors take equal shares.

A smaller branch resistance draws more current. Req of the pair is 1 / (1/R1 + 1/R2), and the voltage across both is V = Iin × Req. Power in each branch is I²R for that branch.
