How to read this manual

  • Outline numbering is kept visible (1.0, 3.1, 9.4.1, etc.).
  • Each major item has short teaching prose and bullets, then a muted Wiki source line under the subsection.
  • Wiki links use full https://wiki.synchro.net/<id> URLs.
  • Where a wiki page is thin or missing, the text says so and points at the closest parent page — it does not invent Synchronet behavior.

Chapters

  • 01Installation — Synchronet Windows and Unix/Linux installation, first launch, and non-root security howtos.
  • 02Configuration — Synchronet configuration, directories, nodes, and configuration files.
  • 03Sysop Commands — Sysop definition, multiple sysops, SCFG, and online sysop commands.
  • 04Users and Access — User management tools and Synchronet access control / ARS.
  • 05Messages and Networking — Message bases, QWK packet networking, and FidoNet with SBBSecho.
  • 06Files, Chat, Externals — File section, chat features, external programs/doors/editors, and text files.
  • 07Servers and Services — Terminal server, services, FTP/web/mail servers, and internet security.
  • 08Customization and Utils — Utility reference, customization (@-codes, Ctrl-A, SIF, GURU), and command-line appendix.
  • 09Sysop Bible — Proper care and feeding of a board — moderation and day-to-day sysop practice.
  • 10Technical and Development — Reference library, QWK specs, development, and extras pointers.
