Technical and Development

Technical Manual (reference library, QWK refs), Development links, Extras (resources, BBS lists). Also points at the User Manual hub.

These pages are often index / thin hubs. This draft maps them and summarizes what is on-wiki without inventing specs.

Technical Manual

Reference Library (ref:index)

The Reference Library page is a short hub for Synchronet-related specifications, with an indexmenu of child pages and an external link to the Synchronet JavaScript Object Model documentation on synchro.net.

Note: The fetched page body is thin by design (indexmenu). Browse https://wiki.synchro.net/ref:index live for the full child list (protocol and format specs as maintained upstream).

Wiki: https://wiki.synchro.net/ref:index
JS object model (external): http://synchro.net/docs/jsobjs.html

QWK Format

Canonical packet layout reference for offline mail and QWKnet debugging/tooling. Sysops doing day-to-day hub calls rarely need it; developers and integrators do.

Wiki: https://wiki.synchro.net/ref:qwk

QWK Network Extensions

Extensions beyond classic QWK used in Synchronet/DOVE-Net style networking. Pair with the base QWK reference when writing or troubleshooting networking tools.

Wiki: https://wiki.synchro.net/ref:qwknet

Development

Development Update (install:dev)

Documents how to obtain and run development / non-stable Synchronet builds (update procedures distinct from the stock Windows installer or release Unix build). Use when you intentionally track upstream between releases. Keep production boards on stable unless you are prepared to debug.

Wiki: https://wiki.synchro.net/install:dev

Development hub (dev:index)

Thin index page with pointers to:

  • JavaScript customization docs (custom:javascript)
  • Git web access / issue database: https://gitlab.synchro.net/
  • Linux debugging howto (howto:gdb)
  • Recent commit log (gitpushlog SSJS on synchro.net)
  • Historical development notes

Wiki: https://wiki.synchro.net/dev:index

Linux Debugging (howto:gdb)

How-to for debugging Synchronet on nix with GDB* (symbols, reproducing crashes, useful breakpoints/backtraces as documented). Essential when filing useful crash reports against development builds.

Wiki: https://wiki.synchro.net/howto:gdb

User Manual (caller-facing pointer)

Not expanded in this sysop-focused draft set, but the outline’s User Manual block starts at:

  • https://wiki.synchro.net/user:index

Child topics include Classic shell, default login, settings, mail, message base, files, chat, text files, doors, QWK menu, and control-key commands. What a caller sees depends on the command shell and modules you installed — document your board’s differences in local text files.
