Refine tree

Basic minerals in No Man's Sky, and the refiner edges that join them. Pick a material. Converts from lists recipes that output it. Converts to lists recipes that spend it. Ratios are community data — a game update can change a recipe. Plants, gases, and alloys stay out of this first set, except oxygen, which the mineral loops need.

Sources

Community refine data, not an official Hello Games table. Process names and ratios were checked against the Miraheze wiki and a 6.50 refiner dump dated 1 September 2026. Activated metals, quartzite, pugneum, plants, and atmospheric gases are omitted on purpose. Adding an edge is a new object in the recipe file.
