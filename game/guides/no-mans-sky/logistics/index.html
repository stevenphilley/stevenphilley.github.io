Mining and crops

Extractors and planted crops are counted from a base’s Objects list. The save does not say which resource an extractor pulls, or the hotspot class, so those stay blank until you set them. A rate appears only from a cited ceiling or a crop’s documented grow time. Anything you type is marked user-entered. Approximate figures are marked ~.

A demand is a hold, an item, and a quantity. Group them into a project. Pins and a recipe’s direct build cost can seed one. The shortfall is what you do not have anywhere. A transfer moves stock you already have. What is still short is expanded on the refine graph. Ticking a transfer updates the inventory.

Find
SearchFilter the table by an in-game name, such as Chromatic Metal or Aronium, or by the save id, such as STELLAR2 or ^ALLOY1.
Item namesStacks use the English in-game name, including craftable technology such as the Jetpack or Gravitino Coil. A procedural id such as ^UP_LASER4#52847 keeps that base item’s name, including the class when the game names one. An id that is not in the list is reworded, and the save id stays beside it and in the tooltip.
Hold, category, placeNarrow the stacks. Not on the map shows holds that are not pinned.
