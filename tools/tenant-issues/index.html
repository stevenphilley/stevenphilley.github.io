    Tenant issues
    
      
    
    
    
    An organizing record for maintenance and habitability issues. Not legal advice, not a court filing, and not a message to your landlord until you choose to send one. Data stays in this browser and in the text file you download. Nothing is uploaded.
    
    
    Issues
    
    
    
      Issues
      
        
    AddAdd issue opens a blank record. Title, room, description, category, priority, and status. Work order numbers can be several, separated however you like.
    
        
    DatesDate first noticed, date reported, follow-up due, and resolved date. How reported is portal, email, phone, or in person. Who was contacted is a name or office.
    
        
    StatusNew, Reported, Acknowledged, Scheduled, In progress, Resolved, Closed, or Disputed/Unresolved. Changing Status writes a dated note so the change stays in the history.
    
        
    Edit / deleteEdit on a card, or the title. Delete asks first. Delete removes it from this browser only. A file you already downloaded is left as it was.
    
          
    
    
    
    Activity log
    
    
    
      Activity log
      
        
    A noteEach entry is a date, a note, and an optional new status. Add one when you call, email, or hear back. The list of notes is the history of that issue.
    
        
    Status on a noteIf you pick a status on a new note, the issue’s status updates to match. Older notes keep the status you stored on them.
    
        
    Edit a noteChange the date, the wording, or the recorded status in the row. Delete note removes that line only.
    
          
    
    
    
    The list
    
    
    
      The list
      
        
    CountsEach status shows how many issues are in it. All is the full list. Open and overdue follow-ups are counted under the buttons. A count filters the list. Search and sort still apply.
    
        
    Days openFrom the date first noticed, or the date reported if noticed is blank, through today. Resolved and Closed stop at the resolved date when you have one.
    
        
    OverdueA follow-up date before today, on an issue that is not Resolved or Closed, is marked on the card. Due today is marked separately. Save writes the whole list, not only the rows on screen.
    
          
    
    
    
    Save, load, new list
    
    
    
      Save, load, new list
      
        
    AutosaveThe list is stored in this browser as you type. Another device does not see it. Clearing site data clears it.
    
        
    Save .txtDownloads a plain text file: a readable report, then a JSON block between BEGIN and END markers. Load reads that block and restores every field and every note.
    
        
    Load .txtPick a file this page saved. If the browser already has issues, it asks before replacing them. A file without the markers will not load.
    
        
    New listAsks, then clears the browser copy. Download a .txt first if you still want the old list. New list does not delete a file already on disk.
    
          
    
    
    
    Summary and print
    
    
    
      Summary and print
      
        
    Copy summaryCopies the readable report, without the JSON block, so you can paste it into an email or a letter.
    
        
    PrintOpens the print dialog with that same report. The buttons and the form stay off the page.
