How it works

  • Latency — several tiny downloads; the median round-trip is the ping.
  • Download — ramps file size and may open a few parallel streams so a single TCP flow does not cap a fast line.
  • Upload — posts blobs to the same public endpoint. Some networks or browsers throttle or block large POSTs; if upload fails, ping and download still stand.
  • This page is static GitHub Pages. There is no speed server here — only the browser and Cloudflare’s public test URLs.

Read it honestly

  • Approximate. Wi-Fi, VPN, browser tabs, CPU, and the particular Cloudflare colo you land on all move the number.
  • Not a lab instrument and not an ISP dispute tool. Re-run, then compare with your provider’s own test if you need a second opinion.
  • Credit: measurement traffic goes to speed.cloudflare.com public __down and __up endpoints. Cloudflare can see those requests the way any CDN sees a download. This page does not post your scores anywhere else.
  • Not affiliated with Cloudflare, Ookla, Speedtest.net, or any ISP.
